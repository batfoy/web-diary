# КОНТЕКСТ ПРОЕКТА: Веб-дневник (аналог My Diary)

## Обо мне
Технолог на заводе ЧПУ (не программист, но технарь). Делаю проект с помощью ИИ, по маленьким шагам. 
Уровень: новичок, но с опытом работы в 3D-моделировании и логическом мышлении.

## О проекте
Браузерный дневник по мотивам приложения "My Diary — Journal with Lock". 
Чистый HTML/CSS/JS, без фреймворков. Работает в браузере на телефоне и ПК.

## Философия проекта (ВАЖНО)
- Дневник — НЕ трекер привычек. Никакого давления, никаких серий дней, никаких красных крестиков.
- Пропуск дня — это нормально. Человек жил, а не "плохо себя вёл".
- Никаких системных попапов (alert/confirm) — только кастомные модалки и тосты.
- Напоминания мягкие: "Давно не виделись, есть что добавить?" — без чувства вины.
- Эмодзи настроения: от 😡 (внизу) до 🥰 (вверху) — хорошее настроение визуально выше.
- График обрывается при пропуске > 2 дней, соединяется при пропуске 1-2 дней.

## Технический стек
- Один файл `index.html`
- Один файл `style.css` (CSS-переменные для 3 тем)
- Один файл `script.js` (без модулей, обычный скрипт)
- Хранение: `localStorage` (ключ `my_web_diary_entries_v2`)
- Никаких библиотек, всё нативно

## Что УЖЕ сделано (текущее состояние — ЗАФИКСИРОВАНО)

### Структура интерфейса:
1. **Шапка** (зафиксирована сверху): гамбургер-меню, заголовок, поиск (строка внутри шапки, скрывается/появляется)
2. **Боковое меню** (сайдбар): Календарь, Тема (3 темы: светлая/тёмная/пастельная + плашка "скоро"), Экспорт, Импорт. Закрывается по клику на фон или свайпу влево.
3. **Главный экран**: 
   - Цитата дня (31 цитата, меняется по клику плавно, раз в день автоматически)
   - Календарь (только на ПК > 768px, виден сразу)
   - График настроения на Canvas
   - Список записей (карточки)
4. **FAB-кнопка "+"** — светящаяся, по центру снизу
5. **Модалки**:
   - Выбор настроения (10 эмодзи, открывается поверх модалки создания через класс `.top-layer`)
   - Создание/редактирование записи (дата через календарь-пикер, эмодзи настроения кликабельно)
   - Подтверждение удаления
   - Календарь (модалка)
   - Записи выбранного дня
   - Напоминание о записях (если не писал ≥ 2 дней)

### Функции:
- Создание, редактирование, удаление записей
- Множественное удаление (long press на карточку → режим выбора → кнопка поиска превращается в 🗑️ с счётчиком)
- Поиск по тексту, заголовку и настроению
- График настроения на Canvas (10 уровней, обрыв при пропуске > 2 дней)
- Календарь с переключением месяцев и плавной анимацией
- Клик по дню в календаре → модалка со списком записей этого дня
- Выбор даты через календарь (при создании/редактировании)
- Экспорт/импорт в JSON (импорт объединяет, не перезаписывает)
- Автосохранение черновика (не реализовано в текущей версии — можно добавить)
- Напоминание при загрузке, если записей нет ≥ 2 дней
