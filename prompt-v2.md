 ПРОМПТ ДЛЯ ВОССОЗДАНИЯ ТЕКУЩЕГО ПРОЕКТА (Vanilla JS v2.0)
🎯 ЗАДАЧА
Создать полнофункциональное веб-приложение "Мой Веб-Дневник" — PWA (Progressive Web App) на чистом JavaScript без фреймворков. Приложение должно работать офлайн, устанавливаться на устройства как нативное и иметь функционал, вдохновленный приложениями My Diary и Journey.
📁 СТРУКТУРА ПРОЕКТА
web-diary/
├── index.html          # Главный HTML-файл
├── style.css           # Все стили (CSS-переменные для тем)
├── script.js           # Вся логика приложения (~2000 строк)
├── db.js               # Обёртка над IndexedDB
├── sw.js               # Service Worker для офлайн-работы
├── manifest.json       # PWA манифест
├── icon-192.png        # Иконка 192x192
└── icon-512.png        # Иконка 512x512
🏗️ АРХИТЕКТУРА
1. Хранение данных: IndexedDB
База данных: MyWebDiaryDB, версия 1
Хранилище: entries (ключ id, индексы date, updatedAt)
Миграция: при первом запуске v2.0 данные из localStorage автоматически переносятся в IndexedDB
Функции в db.js: initDB(), dbGetAll(), dbPut(), dbDelete(), dbClear(), saveAllToIndexedDB(), migrateFromLocalStorage()
2. PWA (Progressive Web App)
manifest.json: имя, иконки, тема, display: standalone, ориентация portrait
sw.js: кэширует все ресурсы (HTML, CSS, JS, иконки) для офлайн-работы
Service Worker регистрируется в index.html
Кэш-версионирование: CACHE_NAME = 'my-web-diary-v2.0'
3. Темы оформления
Три темы через CSS-переменные:
Светлая (по умолчанию): --bg-color: #f5f5f5, --accent-color: #4CAF50
Тёмная: --bg-color: #1e1e1e, --accent-color: #66bb6a
Пастельная: --bg-color: #fdf6f0, --accent-color: #f48fb1
Тема сохраняется в localStorage под ключом my_web_diary_theme_v1.
📊 МОДЕЛЬ ДАННЫХ
Каждая запись имеет строгую структуру:
javascript
{
  id: "1698765432100",              // string, timestamp создания
  date: "2026-10-28T12:00:00.000Z", // string, ISO дата публикации (НЕ МЕНЯЕТСЯ при редактировании)
  createdAt: 1698765432100,         // number, timestamp создания
  updatedAt: 1698765432100,         // number, timestamp последнего сохранения
  editedAt: 1698765432100,          // number | null, timestamp редактирования
  title: "Мой заголовок",           // string
  content: "Текст с <img class='inline-emoji' src='...' />", // string, HTML
  mood: "😊",                       // string, эмодзи настроения
  wordCount: 42,                    // number
  tags: ["#работа", "#идеи"]        // array of strings, lowercase
}
КРИТИЧНО: При редактировании старой записи поле date НЕ меняется. Меняются только updatedAt и editedAt.
🎨 ИНТЕРФЕЙС И UX
Главный экран
Шапка: кнопка меню (☰), заголовок "Мой Дневник", поиск (🔍)
Цитата дня: градиентный блок с цитатой (31 цитата в массиве), клик меняет цитату
Календарь (десктоп): показывается только на экранах >768px, дни с записями показывают эмодзи настроения
Список записей: карточки с датой, заголовком, текстом (2 строки), настроением, тегами
FAB-кнопка: круглая зелёная кнопка "+" внизу по центру для создания записи
Боковое меню (гамбургер)
Выезжает слева, содержит:
📅 Календарь (модальное окно)
📈 Статистика (модальное окно)
↕️ Сортировать записи по... (подменю: Дате создания, Дате изменения)
🎨 Тема (подменю: Светлая, Тёмная, Пастельная)
😊 Настроение (подменю: сетка эмодзи для фильтрации)
📊 График настроений (модальное окно с Canvas)
🏷️ Теги (модальное окно со всеми тегами)
📦 Экспорт / Импорт (подменю: JSON экспорт/импорт, Markdown экспорт)
🔐 PIN-код (подменю: Создать PIN, Сбросить PIN)
Модалка создания/редактирования записи
Шапка:
Слева: кнопка ← (новая пустая запись) / ✓ (есть текст или редактирование) / ✕ (просмотр старой)
Центр: выбор даты (📅 Сегодня / Вчера / дата)
Справа: ✏️ (карандаш, только при просмотре старой записи) и 🗑️ (корзина, только если есть текст или это старая запись)
Поля:
Заголовок (input, readonly в режиме просмотра)
Настроение (эмодзи, кликабельно только в режиме редактирования)
Текст (contenteditable div, поддерживает HTML и inline-картинки)
Тулбар (панель инструментов):
Находится внизу модалки, горизонтально прокручиваемый, содержит кнопки:
📝 Шаблоны (открывает модалку с 4 шаблонами)
🎨 Фон (заглушка "скоро")
😊 Эмодзи (открывает подпанель с паками эмодзи)
Теги (вставляет # в позицию курсора)
Aa Текст (заглушка "скоро")
☰ Список (заглушка "скоро")
⊞ Таблица (заглушка "скоро")
Двухуровневый тулбар:
При нажатии на инструмент (например, 😊) над основной панелью тулбара выезжает подпанель с инструментами. Она закрывается по:
Клику на галочку ✓ в правом верхнем углу подпанели
Повторному клику на ту же кнопку инструмента
Клику в поле ввода текста или заголовка
Панель эмодзи (в тулбаре)
Сверху: горизонтально прокручиваемая панель паков эмодзи (иконки паков)
Снизу: сетка эмодзи (8 колонок на десктопе, 7 на мобильных)
Поддержка двух типов эмодзи: строки (стандартные Unicode) и объекты {type: 'img', src: '...', alt: '...'} (кастомные картинки)
При клике на эмодзи он вставляется в позицию курсора, панель НЕ закрывается
⚙️ КЛЮЧЕВАЯ ЛОГИКА
Автосохранение
При вводе текста в заголовок или поле ввода срабатывает onEntryFieldInput()
Через 500мс после последнего ввода вызывается saveCurrentEntry()
Если запись новая и есть текст — создаётся в IndexedDB, editingEntryId устанавливается
Если запись существующая — обновляется в IndexedDB
Никаких черновиков! Запись создаётся сразу при появлении первого символа
Состояния модалки записи
Четыре состояния, определяются классами на #entry-modal:
state-new-empty: новая запись, пусто → кнопка ←, корзина скрыта
state-new-filled: новая запись, есть текст → кнопка ✓, корзина видна
state-view: просмотр старой записи → кнопка ✕, виден карандаш ✏️
state-edit: редактирование старой записи → кнопка ✓, карандаш скрыт
Сортировка
По умолчанию: по дате создания (новые сверху)
Режимы: created (по дате создания), updated (по дате изменения)
Сохраняется в localStorage под ключом my_web_diary_sort_mode_v1
При сортировке по дате изменения отредактированные записи поднимаются вверх
Фильтрация
По дате: клик на день в календаре
По тегу: клик на тег в модалке тегов
По настроению: клик на эмодзи в подменю гамбургера
Поиск: по тексту и заголовку (регистронезависимый)
Все фильтры взаимно исключают друг друга
PIN-код
Хранится в localStorage под ключом my_web_diary_pin_v1
При первом запуске: PIN не запрашивается, пользователь создаёт его через меню
При последующих запусках: если PIN установлен — показывается модалка ввода
4-значный код, ввод через цифровую панель, визуальная обратная связь (точки, тряска при ошибке)
Экспорт/Импорт
JSON экспорт: полный бэкап с версией и массивом записей
JSON импорт: дедупликация по id, добавление только новых записей
Markdown экспорт: хронологический порядок, экранирование спецсимволов, теги без #
🛠️ ТЕХНИЧЕСКИЕ ДЕТАЛИ
Rich Text ввод
Поле ввода: <div contenteditable="true"> вместо <textarea>
Картинки-эмодзи: <img class="inline-emoji" contenteditable="false">
Функция insertEmojiAtCursor() использует window.getSelection() и Range API
Функция getPlainTextFromHTML() очищает HTML для подсчёта слов и тегов
Календарь
Дни недели: Пн-Вс (смещение для первого дня месяца)
Дни с записями: показывают эмодзи настроения первой записи дня
Сегодняшний день: выделен рамкой акцентного цвета
Анимация переключения месяцев: slide-left / slide-right
График настроений
Canvas 2D, высота 180px (220px в модалке)
Ось Y: эмодзи настроений (😡 😕 😊 🥰)
Ось X: дни месяца
Линия соединяет точки, если разница между днями ≤ 2
Показывает среднее настроение и количество записей
Статистика
Всего записей, всего слов, средняя длина
Дней с записями из общего количества дней с первой записи (% активности)
Самое частое настроение
Самая длинная и короткая запись
Дата первой записи
Напоминание
Если последняя запись была ≥2 дней назад — показывается модалка "Давно не виделись!"
Кнопки: "Позже" (закрыть) и "Написать" (открыть новую запись)
📱 АДАПТИВНОСТЬ
Мобильные (<480px): уменьшенные отступы, шрифты, сетка эмодзи 7 колонок
Планшеты/Десктоп (>768px): показывается календарь на главной странице
Модалки: max-width: 500px, height: 80vh (90vh на мобильных)
Тулбар: горизонтальный скролл, кнопки min-width: 44px для удобного нажатия
🚀 ЗАПУСК И РАЗРАБОТКА
Локальный запуск
Только через HTTP-сервер (Live Server в VS Code), НЕ через file://
Service Worker и манифест не работают через file:// протокол
При разработке: DevTools → Network → "Disable cache" или sw.js → "Update on reload"
Обновление кэша PWA
Изменить CACHE_NAME в sw.js (например, my-web-diary-v2.1)
Или добавить версию к файлам: script.js?v=2.1
