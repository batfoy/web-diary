# Insight — Дневник и Настроение

**Insight** — это PWA-приложение (Progressive Web App) для ведения дневника и отслеживания настроения. Написано на чистом JavaScript без фреймворков.

## 🎯 О проекте
Не просто дневник, а умный трекер эмоций. Приложение помогает находить закономерности между событиями (триггерами) и вашим состоянием, используя продвинутые алгоритмы расчета.

## ✨ Ключевые особенности
- **Умный расчет настроения:** учитывает время записи (утро/вечер), чтобы не усреднять кризисные дни.
- **Инсайты и триггеры:** анализ того, как разные события влияют на ваше настроение (с учетом уровня уверенности).
- **Быстрая запись:** возможность отметить только эмоцию и триггеры, без текста.
- **Rich Text редактор:** поддержка шрифтов, цветов, списков, таблиц и картинок.
- **PWA:** работает офлайн, устанавливается на главный экран устройства.
- **Приватность:** все данные хранятся локально в IndexedDB, без серверов.
- **PIN-код:** опциональная защита дневника.

## 🛠️ Технологии
- Vanilla JavaScript (ES6+)
- IndexedDB (хранение данных)
- Canvas API (графики)
- Service Worker (офлайн-режим)
- CSS-переменные (4 темы оформления)

## 🚀 Запуск
Для работы приложения требуется локальный HTTP-сервер (например, Live Server в VS Code).
